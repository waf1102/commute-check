This plan establishes the foundational database layer for the application. It introduces the necessary libraries, creates the database models using SQLModel, sets up the database connection, and implements basic security for sensitive data.

**Purpose:** To prepare the application for persisting user settings, moving from transient in-memory data to a stable SQLite backend.
**Output:** A new database model, connection management, and encryption utilities.
</objective>

  <name>Task 3: Create Database Engine and Models</name>
  <files>
    - app/database.py
    - app/models.py
  </files>
  <behavior>
    - The `UserConfig` model in `app/models.py` should be a SQLModel table.
    - It must include fields for `id`, `name`, `lat`, `lon`, `webhook_url`, and all thresholds from the original `UserThresholds` model.
    - `webhook_url` should be of type `bytes` to store encrypted data.
    - `app/database.py` should provide a function `create_db_and_tables` that creates the database and the `UserConfig` table.
  </behavior>
  <action>
    1.  **Create `app/database.py`:**
        - Define the SQLite database URL: `sqlite:///commute_check.db`.
        - Create the `sqlmodel.create_engine` with `connect_args={"check_same_thread": False}`.
        - Create a `get_session` dependency function for FastAPI.
        - Create an `create_db_and_tables` function to initialize the database.

    2.  **Update `app/models.py`:**
        - Import `SQLModel`, `Field`, and `Optional` from `sqlmodel`.
        - Remove the `UserThresholds` Pydantic model.
        - Create a new `class UserConfig(SQLModel, table=True):` model.
        - This model should contain all the fields from `UserThresholds` plus:
            - `id: Optional[int] = Field(default=None, primary_key=True)`
            - `name: str` (e.g., "Default")
            - `lat: float`
            - `lon: float`
            - `webhook_url: Optional[bytes] = None`
            - `schedule_time: Optional[str] = None` (e.g., "07:00")
        - Keep the other models (`Status`, `HourlyWeather`, `AssessmentResult`) as they are (they can remain Pydantic `BaseModel`).
  </action>

  </verify>
