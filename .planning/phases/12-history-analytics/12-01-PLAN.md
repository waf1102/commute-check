  <behavior>
    - The `AssessmentHistory` model should be a SQLAlchemy model.
    - It must include `id`, `user_id` (as a foreign key to `users.id`), `timestamp`, `commute_type`, `commute_distance_km`, and `duration_minutes`.
    - It should follow the "Wide Table" pattern described in the research, including all necessary fields for future analytics.
    - The `user_id` should be indexed for efficient lookups.
  </behavior>
  <action>
Modify `app/models.py` to add the `AssessmentHistory` class. This class will map to the `assessment_history` table in the database.

Based on the research (Pattern 1: Wide Table), define the following columns:
- `id`: Integer, Primary Key
- `user_id`: Integer, Foreign Key to `users.id`, nullable=False, index=True
- `timestamp`: DateTime, nullable=False, index=True
- `commute_type`: String (e.g., 'driving', 'riding'), nullable=False
- `commute_distance_km`: Float
- `duration_minutes`: Float
- `created_at`: DateTime, with a default of `func.now()`

This directly addresses `HIST-01` by creating the storage model.
  </action>
