<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| User -> Browser | Storage of sensitive authentication token. |

## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-11-06 | Information Disclosure | JWT in Browser | Mitigate | The JWT will be stored in `localStorage`. While this is standard practice, it is vulnerable to XSS. The Svelte framework provides some default XSS protection by escaping content. The token will be sent over HTTPS in production. For this phase, localStorage is acceptable. Future hardening could move to httpOnly cookies. |
</threat_model>
